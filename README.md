# 🔐 whitehacker-lab

whitehacker-lab は、Webセキュリティ・暗号・CTF・脅威分析を  
**ブラウザだけで学べる統合型ハッカーラボ** です。

## 📦 ローカルで開く

whitehacker-lab はサーバー不要で動作します。  
以下のいずれかの方法で index.html を開いてください。

### 方法1：ダブルクリック
- whitehacker-lab/index.html をダブルクリックするだけで起動します。

### 方法2：VSCode Live Server
1. VSCode を開く
2. 拡張機能「Live Server」をインストール
3. index.html を右クリック → “Open with Live Server”
4. 自動リロードが有効になり開発が快適になります
